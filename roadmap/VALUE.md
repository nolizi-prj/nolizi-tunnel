# VALUE — Pumasi Tunnel

**Core Value Proposition:** Unmetered, multi-protocol localhost tunnels with permanent custom domains, raw TCP port exposure, zero-client SSH access, and local webhook debugging — without per-seat taxes, artificial session timeouts, or interstitial HTML warning blocks.

---

## The 5 Pillars of Value

1. **Zero-Client Frictionless Access**:
   - Tunnels can be created with a standard one-line `ssh -R` command available on every Mac, Linux, and Windows machine without downloading any binary.
2. **Permanent Free Custom Subdomains**:
   - Developers get stable URLs (`myapi.pumasi.link`) that do not break across restarts or charge $10–$18/month.
3. **Native Raw TCP Exposure**:
   - Forwarding non-HTTP protocols (Windows Remote Desktop 3389, PostgreSQL 5432, SSH 22) directly to a domain with zero client-side proxy software needed.
4. **Zero Interstitial Blockers**:
   - Webhook testing (Stripe, GitHub, Discord, Slack) works out of the box with raw JSON payloads and zero HTML interstitial error screens.
5. **Built-in Local Webhook Inspector**:
   - Full traffic inspection, header analysis, JSON formatting, and one-click request replay running on `http://127.0.0.1:4040`.
