## 1. Coherence & Internal Consistency

- **Architectural Decoupling ([`SPEC.md` §2–§3](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L17-L51)):**  
  The root cause of announcing before binding was the coupling in legacy `bindTCP` between creating the socket listener (`net.Listen`) and initiating the multiplexed stream accept loop (`serveTCP`), which depends on an active `tunnelSession`. On the agent path, instantiating `mux.Server(conn)` immediately spawns a background `readLoop` goroutine on the raw connection; doing so before writing the handshake response creates a race that corrupts handshake frame processing. Splitting `bindTCP` into:
  1. [`listenTCP(agentID string, port int) (*tcpListener, error)`](file:///home/m/dev/pumasi-tunnel/relay/tcp.go#L63-L78) — binds the OS listener, stores it in `r.tcpListeners`, and safely buffers incoming visitor connections in the OS TCP backlog.
  2. [`serveTCP(session tunnelSession, l *tcpListener, subdomain string)`](file:///home/m/dev/pumasi-tunnel/relay/tcp.go#L80-L112) — accepts visitor connections and pipes them into multiplexer streams once the session handshake completes.  
  This cleanly resolves the circular dependency without protocol corruption or dropped connections.

- **Elimination of Redundant Registry Lookup ([`SPEC.md` §3.2](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L53-L70)):**  
  Modifying `authorize` to return `(core.AuthResponse, int, error)` supplies the allocated port directly to `ServeAgent` and `ServeSSH`. Eliminating `r.registry.Lookup(resp.Subdomain + "." + r.cfg.BaseDomain)` completely removes the mechanism of the SSH path's silent skip rather than attempting to patch it with conditional fallback branches ([`lessons/L-007`](file:///home/m/dev/pumasi/lessons/L-007-restating-a-rule-forks-it.md)).

- **Amendments 1–3 Integration ([`SPEC.md` §6](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L120-L243)):**  
  - **§6.1 (Reachability Correction):** Accurately notes that `relay.New` rejects `BaseDomain: ""` at startup, identifying the real trigger as a leading space in `-domain` (`" pumasi.link"`), where `core.NewRegistry` trims the domain but lookup key construction did not.
  - **§6.2 (B-2 Assertion Refinement):** Corrects the SSH refusal assertion: the bind refusal legitimately contains the address string (`pumasi: relay: binding public port ...`), so B-2 correctly distinguishes refusals via `sshTell` from announcements via `sshGreet` (`sshGreetingMarker`).
  - **§6.4 (Refusal Lifecycle Ordering):** Corrects the teardown sequence on bind failure to **unregister, then tell**. Because `listenTCP` immediately returns the port to `PortPool`, writing the error frame first created a race window where the pool viewed the port as free while the registry still viewed it as occupied.
  - **§6.5 (Acceptance Fixture Isolation):** Replaces the shared port allocation in test fixtures with `bindOrderPorts(t)` giving distinct port blocks per test, eliminating harness races during concurrent relay listener cleanup without introducing arbitrary sleeps.

## 4. Edge Cases & Boundary Handling

1. **HTTP Tunnels (`resp.TCPAddr == ""`):** Handled cleanly without triggering `listenTCP` or `serveTCP`.
2. **Handshake Write Failures After Listen:** If writing `AuthResponse` fails after `listenTCP` succeeds, the `abandon()` closure guarantees listener closure and unregistration.
3. **Session Teardown:** Handled symmetrically via `session.CloseChan()`, `defer r.releaseTCP(resp.AgentID)`, and `r.registry.UnregisterAgent`.
4. **Port Pool Exhaustion:** Checked and rejected inside `authorize` prior to socket binding.
