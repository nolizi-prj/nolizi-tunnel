## 1. Coherence & Internal Consistency

- **Architectural Decoupling ([`SPEC.md` §2–§3](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L17-L51)):**  
  The root cause of announcing before binding in the legacy design was the structural coupling in `bindTCP` between socket listener creation (`net.Listen`) and accept loop initialization (`serveTCP`), which requires an instantiated `tunnelSession`. On the agent path, instantiating `mux.Server(conn)` immediately spawns a background `readLoop` on the connection; doing so before writing the handshake response puts the multiplexer reader on a connection still actively undergoing raw frame exchange.  
  The specification resolves this by cleanly splitting `bindTCP` into:
  1. [`listenTCP(agentID string, port int) (*tcpListener, error)`](file:///home/m/dev/pumasi-tunnel/relay/tcp.go#L63-L78) — binds the OS socket, registers the listener in `r.tcpListeners`, and allows the OS kernel TCP accept queue to buffer incoming visitor connections safely.
  2. [`serveTCP(session tunnelSession, listener *tcpListener, subdomain string)`](file:///home/m/dev/pumasi-tunnel/relay/tcp.go#L80-L112) — initiates the visitor accept loop and pipes incoming streams once the session handshake completes.
- **Elimination of Redundant Registry Lookup ([`SPEC.md` §3.2](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L53-L70)):**  
  Modifying `authorize` to return `(core.AuthResponse, int, error)` supplies the allocated port directly to `ServeAgent` and `ServeSSH`. Deleting `r.registry.Lookup(resp.Subdomain + "." + r.cfg.BaseDomain)` completely eliminates the SSH path's silent skip defect at the source rather than masking it with conditional branches ([`lessons/L-007`](file:///home/m/dev/pumasi/lessons/L-007-restating-a-rule-forks-it.md)).
- **Transparent Amendment Tracking ([`SPEC.md` §6](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L120-L270)):**  
  All discovered anomalies and test harness limitations were amended in the open rather than altered quietly inside frozen cases:
  - **§6.1 (Reachability):** Notes that `relay.New` rejects `BaseDomain: ""` at startup and identifies the actual trigger as a leading space in `-domain` (`" pumasi.link"`), where `core.NewRegistry` trimmed the domain but lookup key construction did not.
  - **§6.2 (B-2 Refinement):** Corrected the assertion to distinguish `sshTell`'s refusal from `sshGreet`'s announcement (`sshGreetingMarker`), since the bind refusal legitimately contains the port address.
  - **§6.4 (Refusal Lifecycle):** Corrected the failure branch to **unregister, then tell**. Because `listenTCP` releases the port to `PortPool` upon failure, reporting the error prior to unregistering opened a race where the pool saw the port as free while the registry recorded it as occupied.
  - **§6.5 & §6.6 (Harness Isolation):** Implemented `bindOrderPorts(t)` to give each test case an isolated block of ports below the ephemeral port range, preventing teardown races without relying on sleeps or retries.

## 4. Edge Cases & Boundary Handling

1. **HTTP Tunnel Isolation:** When `resp.TCPAddr == ""`, both `ServeAgent` and `ServeSSH` bypass `listenTCP` and `serveTCP` cleanly.
2. **Post-Listen Handshake Failures:** If `EncodeAuthResponse` or `writeFrame` fails after `listenTCP` succeeds, the `abandon()` closure in [`relay.go`](file:///home/m/dev/pumasi-tunnel/relay/relay.go#L192-L197) guarantees that `releaseTCP` and `UnregisterAgent` are executed.
3. **Session Teardown:** Handled symmetrically via `<-session.CloseChan()`, `defer r.releaseTCP(resp.AgentID)`, and `r.registry.UnregisterAgent`.
4. **Port Pool Exhaustion:** Pre-validated in `authorize` prior to socket binding.
