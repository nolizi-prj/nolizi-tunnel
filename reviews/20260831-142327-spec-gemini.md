## 1. Coherence & Internal Consistency

- **Decoupling Listener Creation from Session Forwarding ([`SPEC.md §2–§3.1`](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L17-L51)):**  
  The root constraint enforcing the legacy announce-before-bind order was the coupling inside `bindTCP` between OS socket binding (`net.Listen`) and the session stream accept loop (`serveTCP`). Because `mux.Server(conn)` starts an immediate `readLoop` goroutine on the raw connection, constructing the mux session before sending the handshake response corrupted handshake frame parsing. Splitting `bindTCP` into:
  1. `listenTCP(agentID string, port int) (*tcpListener, error)` — binds the OS port and registers the listener, holding early incoming visitor connections in the OS kernel TCP accept queue.
  2. `serveTCP(session tunnelSession, listener *tcpListener, subdomain string)` — drains accepted connections into multiplexed streams once the tunnel session is active.  
  This cleanly resolves the circular dependency without introducing races or protocol desynchronization.

- **Elimination of the Registry Round-Trip ([`SPEC.md §3.2`](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L53-L70)):**  
  Modifying `authorize` to return `(core.AuthResponse, int, error)` supplies the allocated TCP port directly to `ServeAgent` and `ServeSSH`. This removes the redundant `r.registry.Lookup(resp.Subdomain + "." + r.cfg.BaseDomain)` call. Per [`lessons/L-007`](file:///home/m/dev/pumasi/lessons/L-007-restating-a-rule-forks-it.md), deleting the redundant round-trip eliminates the root cause of the silent skip defect rather than masking it with conditional branches.

- **Refusal Ordering & State Synchronization ([`SPEC.md §6.4`](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L179-L204)):**  
  Amendment 2 addresses the race condition where `listenTCP` releases the port back to `core.PortPool`, but the registry still retained the tunnel mapping until `UnregisterAgent` executed. By enforcing **unregister before tell** on the failure path in both `ServeAgent` and `ServeSSH`, the registry and port pool states are fully synchronized before the client is informed or subsequent requests arrive.

## 3. Acceptance Cases & Test Invariants ([`L-006`](file:///home/m/dev/pumasi/lessons/L-006-tests-that-cannot-fail.md))

Every acceptance case in [`acceptance/CASES.md`](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/acceptance/CASES.md) (implemented in [`relay/bindorder_test.go`](file:///home/m/dev/pumasi-tunnel/relay/bindorder_test.go)) is deterministic and directly exercises the named clauses:

1. **B-1 (Agent Path Ordering - `TestAgentIsNotToldAnAddressItCannotBeGiven`):**  
   Pre-occupies the public TCP port with a foreign listener so `listenTCP` unconditionally fails on OS bind. Asserts that the client receives a `FrameError` and **never** receives an `AuthResponse` containing `TCPAddr`. Deterministic; fails if announce precedes bind.
2. **B-2 (SSH Path Ordering - `TestSSHIsNotToldAnAddressItCannotBeGiven`):**  
   Pre-occupies the TCP port over a real SSH connection. Correctly distinguishes between a refusal message (`pumasi: binding public port ...`) and a valid tunnel greeting (`forwarding to your local port...`), verifying no greeting is sent when binding fails.
3. **B-3 & B-4 (Lookup Elimination - `TestTCPOnlyRelayAnnouncesAnAddressThatAnswers`, `TestSSHTCPOnlyRelayNeverGreetsADeadAddress`):**  
   Configures `BaseDomain: " pumasi.link"`. Because `relay.New` accepts leading whitespace while `core.NewRegistry` trims it, registry lookup under the legacy code returned `ErrForeignHost` 100% of the time. The tests assert that the announced address is bound, answers immediately, and passes bidirectional data.
4. **B-5 (Port Pool & Registry Release - `TestPortReturnsToThePoolWhenTheBindFails`):**  
   Forces a bind failure on Agent 1, clears the obstruction, and verifies Agent 2 can immediately claim and bind the port, proving both `pool.Release` and `r.registry.UnregisterAgent` ran without leakage.
5. **B-6 (End-to-End Regression Invariant - `TestAnnouncedAddressIsTheWorkingAddress`):**  
   Asserts the full happy path over the decoupled `listenTCP`/`serveTCP` lifecycle, executing multiple bidirectional data exchanges.

None of the acceptance cases depend on timing races or conditional assertions (`"if X then Y"`).

## 4. Edge Cases & Boundary Handling

- **HTTP-Only Tunnels (`req.TCP == false`):** Correctly skips `listenTCP` and `serveTCP` without allocating TCP ports.
- **Relays with No TCP Port Range (`TCPPortLow == 0 && TCPPortHigh == 0`):** Refuses TCP requests during `authorize` with clear messaging (`"relay: this relay has no TCP port range configured"`).
- **External Socket Collisions (`EADDRINUSE`):** Handled in `listenTCP`, immediately returning the port to `r.pool` before returning the wrapped error.
- **Post-Bind Handshake Write Failures:** Handled via `abandon()`, releasing the listener, freeing the port, and unregistering the agent.
- **In-flight Visitors in Handshake Window:** Buffered cleanly in the OS listener backlog until `serveTCP` attaches.
- **Session Termination:** Symmetric cleanup guaranteed via `defer r.releaseTCP(resp.AgentID)` and `UnregisterAgent`.
