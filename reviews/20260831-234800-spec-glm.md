## The objection — R-8 can pass while its clause is false (L-006)

CASES.md R-8: clause — "A claim recorded by a handshake that then fails is discarded"; test — `core.TestADiscardedClaimLeavesNothing`; Fails-when — "a bind failure on a first connection locks a name to a token that never opened a tunnel."

The clause and the failure mode are relay-level: §5.1 names all three post-claim failures — "the registry refuses the name as live, the bind fails, the announce fails" — and handshakes and binds live in `relay`. The test sits in `core/reservation_test.go` (CASES.md's own heading) and can only exercise `Discard`'s primitive semantics by supplying the call itself. A relay with **no Discard call sites at all** passes R-8 green while the clause is false in exactly the way its Fails-when column describes. No other case notices: C-1, C-2 and C-4 end in successful handshakes; C-3's background claim succeeds; C-5 is a `Check` refusal; C-6 is refused at the claim itself, creating nothing; D-1 is slice 2. So §5.1's sentence — "the relay calls `Discard` for a claim `created` by that handshake. So a name is never consumed by a connection that never opened" — a clause §9 item 3 presents as one of four "real holes" **closed** — is closed in the spec text and in no acceptance case. This is the identical pattern §9 records against the first draft of C-4 ("a case [that] could pass with its own clause false … inside a spec that cites L-006"), and it violates CASES.md's own header rule: "Every case names **what execution makes it fail**" — the execution R-8 names (a bind failure on a first connection) is one its test cannot perform.

Unlike C-4's untestable half, this one is falsifiable: a relay case can hold a name live so the registry returns `ErrNameTaken` after `Claim` created (or pre-bind the public port so the bind fails), then assert the set is empty and a stranger's token may claim. That case should exist before the freeze. Had §10 actually run "every case" against its named defect, the mismatch would have surfaced; the R-cases' absence from the mutation table is the same finding viewed from the evidence side.
