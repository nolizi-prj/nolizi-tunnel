## 1. Specification & Contract Conformance

The changes implement [`spec/0002-bind-before-announce`](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md) (incorporating Amendments §6.1–§6.5):

1. **Decoupling Listen and Serve ([`SPEC.md §3.1`](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L36-L51)):**  
   - [`relay/tcp.go`](file:///home/m/dev/pumasi-tunnel/relay/tcp.go#L63-L113) splits legacy `bindTCP` into:
     - [`listenTCP(agentID string, port int) (*tcpListener, error)`](file:///home/m/dev/pumasi-tunnel/relay/tcp.go#L63-L78): Binds the OS socket via `net.Listen` and registers the listener in `r.tcpListeners`. On socket bind failure, it releases the port back to `r.pool` immediately.
     - [`serveTCP(session tunnelSession, listener *tcpListener, subdomain string)`](file:///home/m/dev/pumasi-tunnel/relay/tcp.go#L81-L112): Runs the accept and stream forwarding loop once `tunnelSession` is active.
   - This resolves the circular dependency on the agent path where `mux.Server` could not be constructed prior to writing the handshake response. In-flight visitor connections during the handshake window queue safely in the OS TCP accept backlog.

2. **Registry Lookup Elimination ([`SPEC.md §3.2`](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L53-L70)):**  
   - [`authorize`](file:///home/m/dev/pumasi-tunnel/relay/relay.go#L250-L302) now returns `(core.AuthResponse, int, error)`. Both [`ServeAgent`](file:///home/m/dev/pumasi-tunnel/relay/relay.go#L162) and [`ServeSSH`](file:///home/m/dev/pumasi-tunnel/relay/sshingress.go#L162) receive the allocated public port directly.
   - Redundant calls to `r.registry.Lookup` have been eliminated, removing the root cause of the silent skip on configurations like `BaseDomain: " pumasi.link"`.

3. **Agent Path Lifecycle ([`SPEC.md §3.3`](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L71-L83), [`§6.4`](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L179-L204)):**  
   - In [`ServeAgent`](file:///home/m/dev/pumasi-tunnel/relay/relay.go#L173-L188), `listenTCP` executes before `EncodeAuthResponse` and `writeFrame`.
   - On bind failure, `r.registry.UnregisterAgent(resp.AgentID)` runs before writing the error frame, ensuring the port pool and registry state are synchronized before the client is informed.
   - If writing the auth response frame fails after `listenTCP` succeeds, the `abandon()` closure guarantees teardown via `r.releaseTCP(resp.AgentID)` and `r.registry.UnregisterAgent(resp.AgentID)`.

4. **SSH Path Lifecycle ([`SPEC.md §3.4`](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L84-L97), [`§6.4`](file:///home/m/dev/pumasi-tunnel/spec/0002-bind-before-announce/SPEC.md#L179-L204)):**  
   - In [`ServeSSH`](file:///home/m/dev/pumasi-tunnel/relay/sshingress.go#L184-L194), `listenTCP` is called before composing and dispatching `sshGreet`.
   - On bind failure, `r.registry.UnregisterAgent(resp.AgentID)` executes prior to `sshTell`, cleanly refusing without greeting the terminal.
