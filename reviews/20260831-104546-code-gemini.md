## 2. Code Review & Implementation Verification

### 2.1 Configuration Pipeline ([SPEC.md §2](file:///home/m/dev/pumasi-tunnel/spec/0001-public-scheme/SPEC.md#L29))
- In [`cmd/pumasi-relay/main.go`](file:///home/m/dev/pumasi-tunnel/cmd/pumasi-relay/main.go#L45), the `-public-scheme` flag is introduced with default `"http"` and passed cleanly via [`relay.Config.PublicScheme`](file:///home/m/dev/pumasi-tunnel/relay/relay.go#L71).
- In [`relay.New`](file:///home/m/dev/pumasi-tunnel/relay/relay.go#L92), the scheme is validated at startup via [`core.ParsePublicScheme`](file:///home/m/dev/pumasi-tunnel/core/route.go#L43). If invalid, `relay.New` returns an error, preventing startup rather than guessing or silently coercing an invalid value.

### 2.2 Normalization & Failsafe Defaults ([SPEC.md §3](file:///home/m/dev/pumasi-tunnel/spec/0001-public-scheme/SPEC.md#L54))
- [`core.ParsePublicScheme`](file:///home/m/dev/pumasi-tunnel/core/route.go#L43):
  - Normalizes case (`strings.ToLower`) and whitespace (`strings.TrimSpace`).
  - Strips trailing `"//"` suffix (`strings.TrimSuffix(v, "://")`).
  - Correctly maps `""` to `SchemeHTTP` (`"http"`).
  - Explicitly accepts only `SchemeHTTP` and `SchemeHTTPS`.
  - Rejects all unknown/unsupported schemes (`ftp`, `ws`, `gopher`, `htp`, etc.) with [`core.ErrUnknownScheme`](file:///home/m/dev/pumasi-tunnel/core/route.go#L19).
- [`core.NewRegistry`](file:///home/m/dev/pumasi-tunnel/core/route.go#L159):
  - Validates the provided scheme and fails closed to `SchemeHTTP` (`"http"`) if passed an invalid scheme, ensuring downstream consumers never construct unroutable addresses.

### 2.3 Single Source of Truth for URLs ([SPEC.md §1 & §4](file:///home/m/dev/pumasi-tunnel/spec/0001-public-scheme/SPEC.md#L6))
- [`core.Registry.PublicURL`](file:///home/m/dev/pumasi-tunnel/core/route.go#L311) is the sole constructor of tunnel URLs:
  $$\text{PublicURL}(N) = S + \text{"://"} + \text{lower}(N) + \text{"."} + D$$
- All three public surfaces consume this single source of truth:
  1. **CLI `AuthResponse`:** Populated via [`r.registry.PublicURL(name)`](file:///home/m/dev/pumasi-tunnel/relay/relay.go#L255) in `relay.authorize`.
  2. **Apex Console (`/_pumasi/status`):** Populated via [`r.registry.PublicURL(t.Subdomain)`](file:///home/m/dev/pumasi-tunnel/relay/dashboard.go#L71) in `relay.serveStatus`.
  3. **Zero-install SSH Ingress:** Consumes [`resp.URL`](file:///home/m/dev/pumasi-tunnel/relay/sshingress.go#L190) in `relay.ServeSSH` and passes it to `sshGreet`.
- Raw TCP address generation ([`resp.TCPAddr`](file:///home/m/dev/pumasi-tunnel/relay/relay.go#L267)) is unaffected and remains scheme-less (`host:port`).
